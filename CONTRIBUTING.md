# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Fork the repository and clone your fork.
2. Create a branch for your proposed change.
3. Make your changes and test the Bash script.
4. Commit your changes with a descriptive message.
5. Push the branch and open a pull request.

Please describe the purpose of your change clearly. Be respectful when discussing issues and reviewing contributions.
