# Simple Interest Calculator

This repository contains a Bash script that calculates simple interest based on user input.

## Project description

The calculator accepts:
- Principal amount
- Annual rate of interest (percentage)
- Time period (years)

It calculates simple interest using:

`Simple Interest = (Principal × Rate × Time) / 100`

## How to run

```bash
bash simple-interest.sh
```

Enter the requested numbers when prompted. The calculator displays the resulting simple interest.
